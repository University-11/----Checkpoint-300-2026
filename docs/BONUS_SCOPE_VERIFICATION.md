# Верификация заданий со звёздочкой ★ (Бонусный уровень — Слайд 8)

Все бонусные возможности из слайда 8 презентации Axenix полностью реализованы в парсере AST (`JavaCompilerAstParser.java` + клиентский парсер `javaAstParser.js`), выделены в специализированную вкладку **«★ Бонусный Scope (Слайд 8)»** веб-среды и протестированы отдельными эталонными наборами `T15_BonusScopeRecordsEnumsGenerics` и `T16_BonusScopeStreamApiAndCollectors` на монолите `BonusScopeShowcaseMonolith.java`:

| Бонусная возможность (Слайд 8 ★) | Где реализовано в коде | Проверяемый автотест |
| :--- | :--- | :--- |
| **1. `record` и `enum`** | `OrderProcessingMonolith.java` (`record AuditEntry`, `record MetricSnapshot`, `enum OrderStatus`, `enum CustomerTier`), `BonusScopeShowcaseMonolith.java` (`record TransactionRecord` с компактным конструктором, `record MerchantAnalyticsSummary`, `enum PaymentChannel` с полиморфными лямбдами комиссий, `enum RiskTier`) | `T01_DefaultEnterpriseSuite`, `T15_BonusScopeRecordsEnumsGenerics` |
| **2. Дженерики (Generics `<T>`)** | `OrderProcessingMonolith.java` (`interface Identifiable<K extends Comparable<K>>`, `LinkedHashMapCompat<K, V>`), `BonusScopeShowcaseMonolith.java` (`class SmartGenericIndex<K extends Comparable<K>, V>`, обобщённый метод `<R> Map<K, R> transformValues(Function<List<V>, R>)`) | `T15_BonusScopeRecordsEnumsGenerics` |
| **3. Лямбды и `java.util.function`** | `BonusScopeShowcaseMonolith.java`: `Predicate<TransactionRecord>`, `Function<List<V>, R>`, `BiFunction<Double, Integer, RiskTier>`, `DoubleUnaryOperator`, `Supplier<List<TransactionRecord>>`, ссылки на методы `TransactionRecord::merchantId`, `Double::sum` | `T15_BonusScopeRecordsEnumsGenerics` |
| **4. `Stream API` и `Collectors`** | `BonusScopeShowcaseMonolith.java`: `Collectors.groupingBy(..., TreeMap::new, Collectors.toList())`, `Collectors.partitioningBy(...)`, `Collectors.summarizingDouble(...)`, `Collectors.reducing(...)`, `Stream.flatMap(...)`, `Collectors.joining(", ", "[", "]")` + автоматическая оптимизация анти-паттерна `Stream-in-Loop O(n²) → Collectors.groupingBy O(n log n)` (ускорение **11.57x–13.89x**) | `T16_BonusScopeStreamApiAndCollectors` |
